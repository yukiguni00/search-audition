# 出演者検索（非公式）

オーディション EAST・アガり！ステージの出演情報と、直接つながる進出・昇格結果を検索する非公式サイトです。最新情報は各主催者の公式発表をご確認ください。

芸人名（MCを含む）、ライブ名、月、日、時間で検索できます。検索条件はURLに反映され、同じURLを開くと復元されます。お気に入りはブラウザ内だけに保存され、バックアップコードで移行できます。お気に入り情報を検索URLへ含めません。

出場権獲得と出演日時確定は別の情報です。出演部未定の一覧は、すべての部への出演確定を意味しません。劇場所属芸人の通常公演を網羅するサイトではありません。
